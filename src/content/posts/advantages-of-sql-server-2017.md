As IT managers of organisations large and small know, your database server can be one of the most vital components in an IT infrastructure. Get it wrong and you are looking at downtime and spiralling costs.

Microsoft SQL Server 2017 offers a number of benefits to commercial organisations, helping keep companies ticking over as well as providing a competitive edge. Here is what it brings to the table.

## Reduced running costs

You can expect to save a good deal compared with earlier versions. Microsoft put considerable thought into how hybrid cloud models work and came up with new ways of accessing data stored both on premises and in the cloud, evidenced by flexible features such as Stretch Database.

## Better performance

It is quite a claim to say you have become a hundred times faster, but that is what SQL Server 2017 is capable of when responding to some queries. Transaction speeds alone enjoyed a boost of up to thirty times compared with previous versions. All of this saves your team time on data processing tasks.

## macOS and Linux support

SQL Server 2017 was a significant win for cross-platform compatibility, being the first version of the relational database management system to support macOS, Linux and Docker containers. Even if you are not running Windows, there is still every reason to consider it. For existing users who had found themselves tied to Windows, the shackles could finally be removed.

## Improved data science capabilities

SQL Server 2017 incorporates both Enhanced R-Open and Python, expanding your analytics options and increasing the number of data access opportunities. The Advanced Analytics feature puts businesses on the path to making the analytical insights that count when improving operational efficiency, whether you want to overhaul inventory management or tighten up the performance of the database itself.

## Tighter security

As we store an increasing volume of data, security becomes more of a priority. SQL Server 2017 includes encryption barriers that help protect your organisation against malicious parties, giving an enhanced level of security over previous versions. You also have dynamic data masking, and the availability features can provide backup in a disaster recovery scenario.
